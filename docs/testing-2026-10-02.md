# Проверка и оптимизация 0.2.1 — 2 октября 2026

Это отчёт о проверенном объёме, а не утверждение об отсутствии всех возможных ошибок.

## Исправленные проблемы

- HTTP-шлюз допускал управляющие символы и неоднозначные заголовки. Добавлена
  строгая проверка до разбора URL; запросы с телом/upgrade отклоняются.
- При обычном HTTP терялись Cookie, Range, User-Agent и другие сквозные заголовки.
  Они сохраняются; заголовки прокси и соединения удаляются. Пайплайнинг не проходит.
- `ipaddress.is_global` пропускал multicast. Теперь такие адреса запрещены и при
  проверке внешнего IP, и после DNS-разрешения назначения.
- Повреждённый JSON состояния сети мог обрушить проверку/контроллер. Ошибочные
  структуры закрывают сеть, а окно получает понятное неизвестное состояние.
- Сбой создания диска/ISO оставлял полуподготовленную среду. Файлы готовятся во
  временных каталогах; публикация не перезаписывает чужие/существующие файлы.
- Кэш старого Ubuntu не соответствовал обновившемуся подписанному manifest и
  мешал повтору установки. Общий загрузчик проверяет подпись до загрузки образа,
  обновляет неверный кэш и не публикует неподтверждённые файлы.
- Прямой повторный запуск CLI мог менять состояние защиты уже работающей VM.
  Отдельная блокировка диска действует до окончания очистки предыдущего запуска.
- Завершение лаунчера SIGTERM могло оставить дочернюю VM. Теперь оно закрывает
  дочерний процесс и отзывает сетевое разрешение; проверено отдельным тестом.
- Повторное применение nftables могло накапливать правила. Замена только своей
  таблицы выполняется атомарно. Проверено два последовательных применения в госте.
- Ошибка после создания маркера готовности могла остановить повтор установки.
  Обработчик ошибки удаляет маркер, позволяя службе повторить настройку.
- Отключение ssh.service оставляло ssh.socket. Оба юнита теперь маскируются.
- Приостановленная VM считалась остановленной. Контроллер учитывает существование
  VM независимо от состояния её CPU.
- Новая установка зависела от возможности записи рядом с .app. Новый путь —
  пользовательский Application Support; существующая соседняя папка сохраняется.
- Linux-скрипт проверял жёстко заданный путь диска. Теперь он читает конфигурацию
  и проверяет наличие и диска, и ISO.
- SAST-gate мог принять пустой/неуспешный SARIF или пропустить severity расширений
  и уровень по умолчанию. Эти состояния теперь блокируют проверку.
- Для проверки IP явно установлен минимум TLS 1.2, независимо от настроек
  OpenSSL по умолчанию; замечание CodeQL не подавляется.

## Оптимизация

- По умолчанию 3072 МБ / 2 CPU вместо 8192 МБ / 4 CPU.
- В окне доступен выбор 3 ГБ / 2 CPU или 6 ГБ / 4 CPU для остановленной среды.
  Существующие пользовательские настройки автоматически не переписываются.
- Вместо метапакетов XFCE/Xorg — необходимый набор рабочего стола и один драйвер
  ввода; отключён композитор. Firefox и Chromium sandbox сохранены.
- Установочный кэш очищается, журнал ограничен, qcow2 поддерживает discard/TRIM.
  Загруженный установочный образ удаляется после успешного создания диска.
- Контроллер читает только последние 256 КиБ загрузочного журнала, опрашивает
  состояние раз в 2 секунды. Частота сетевой защиты не уменьшалась.

## Фактически выполнено локально

- 69 unit/integration-тестов: реальный локальный TCP, туннель, HTTP-заголовки,
  истечение разрешения, смена IP, сетевое событие, остановка, сбои установки,
  проверки подписей/кэша, блокировка второго процесса, настройки контроллера.
- В локальных тестах сетевое событие закрывало уже установленное соединение
  примерно за 21–25 мс. Это измерение теста, не гарантия времени для любого VPN.
- Полная установка отдельной ARM64 VM с Python 3.12, QEMU/HVF: PASS, 235 секунд
  (проверенный образ Ubuntu уже находился на хосте; загрузка образа в это время
  не входит). Рабочая пользовательская VM не изменялась.
- Реальные окна Claude Desktop 2.9939.4 и Firefox 157.0~build1, XFCE, us/ru,
  маскированные SSH-юниты, прямой доступ запрещён, публичный HTTPS через шлюз
  работает, локальные/служебные адреса через прокси запрещены.
- После открытия обеих программ: `free -m` used 1193 МБ, available 1762 МБ.
  Это простой без входа в аккаунт, не нагрузочный тест большой переписки.
- В госте занято 3.3 ГБ, на хосте qcow2 занял около 3.5 ГБ. Измерение включает
  тестовую утилиту xwininfo; её нет в обычной установке. Размер растёт с данными.
- Обе нативные Mac-сборки (ARM64/Intel) компилируются и проходят codesign verify.
- Bandit: нет medium/high. pip-audit: известных уязвимостей закреплённых Python
  зависимостей не найдено. actionlint и проверка синтаксиса скриптов проходят.

## Ограничения

Нативный запуск VM на Intel Mac, Linux и Windows, установка Homebrew на полностью
чистом Mac, вход в Claude, Cowork и реальные переключения пользовательского VPN
этим прогоном не подтверждены. VPN хоста не отключался. Windows остаётся preview.
Сквозной тест запускается вручную через scripts/integration_vm.py; CI отдельно
проверяет матрицу ОС, сборки, CodeQL, Bandit и SCA. Обычный выбор экономного режима
не удаляет старые гостевые пакеты; облегчённый пакетный состав применяется к новой
установке. Геолокационная проверка не доказывает маршрут каждого сайта при split
 tunneling и не даёт гарантии от блокировки аккаунта.
