# Claude Isolate

[![CI](https://github.com/JFT-git/Claude-isolate/actions/workflows/ci.yml/badge.svg)](https://github.com/JFT-git/Claude-isolate/actions/workflows/ci.yml)

Экспериментальная изолированная Linux-среда для Claude Desktop и Firefox.
QEMU запускает отдельную ОС без общих папок, буфера обмена, камеры, микрофона,
проброса USB и входящих портов. Сетевой шлюз использует системный маршрут хоста:
подходит системный VPN, который направляет **весь трафик шлюза** через туннель.
FlClash не требуется. Это не VPN-клиент и не гарантия отсутствия блокировок аккаунта.

## Платформы и загрузка

| Платформа | Артефакт CI | Состояние |
| --- | --- | --- |
| macOS 14+, Apple Silicon | `Claude-isolate-macos-arm64.zip`, нативный `.app` | Локально проверен запуск VM, Claude и Firefox |
| macOS 14+, Intel | `Claude-isolate-macos-x86_64.zip`, нативный `.app` | Сборка и тесты в CI; запуск VM на Intel ещё не проверен |
| Linux x86_64 / ARM64 | `Claude-isolate-linux-*.zip`, исходники и CLI | Экспериментально; отдельного графического контроллера нет |
| Windows x64 | `Claude-isolate-windows-x64-preview.zip` | Пакет разработчика и тесты; работоспособность QEMU `guestfwd ... cmd` и запуска VM не подтверждена |

Готовые артефакты находятся в **Actions → CI and release → Artifacts**.
По тегу `v*` после успешных тестов и SAST/SCA создаётся предварительный GitHub Release.
Сборка сама по себе не подтверждает работу изоляции на реальном компьютере.
Приложение Claude, Ubuntu, QEMU и диски с аккаунтами в архивы не включаются.

## macOS

Распакуйте `.app` в пользовательскую папку с правом записи, включите системный VPN
и запустите приложение. Кнопки позволяют запустить, остановить и перезапустить среду.
Homebrew, Python 3.12, QEMU и GnuPG устанавливаются при необходимости.
Homebrew.pkg проверяется средствами macOS; при его установке возможен системный
запрос пароля администратора. Затем загружается Ubuntu 24.04, проверяются подпись
закреплённого ключа Ubuntu и SHA256, создаётся отдельный диск до 64 ГБ.
Для VM по умолчанию выделены 8 ГБ RAM и 4 CPU.

Рядом с `.app` появляется **Claude Environment Data**. Не удаляйте её:
там находятся файлы гостя и сеансы входа. Перенос существующей среды потребует
обновить абсолютные пути в её `environment.json`.

Сборки имеют локальную ad-hoc подпись, **без Apple Developer ID и notarization**.
Gatekeeper может потребовать разрешение на открытие в настройках macOS.
Проверяйте источник и SHA256; отключать системную защиту целиком не нужно.
Чистая установка без Homebrew и работа Intel VM требуют отдельного ручного теста.

Рабочий стол, Claude, Firefox, русский/английский язык устанавливаются автоматически.
Переключение: **Alt+Shift / Option+Shift** или индикатор на панели.
Гость использует 1920×1200, XFCE 144 DPI, Claude 150%.
Гостевое окно Mac открывается на весь экран; выход — меню View → Enter Fullscreen.
Вход в аккаунт и принятие условий Firefox выполняет пользователь.

Сборка из исходников:

```sh
python3 macos/build.py --arch arm64
# Intel:
python3 macos/build.py --arch x86_64
```

Результат: `dist/Claude Environment.app`. Нужны инструменты разработчика Apple.

## Linux CLI (экспериментально)

Для Ubuntu/Debian x86_64 установите зависимости:

```sh
sudo apt-get update
sudo apt-get install python3 qemu-system-x86 qemu-utils genisoimage gnupg
```

Для ARM64 вместо `qemu-system-x86` нужны `qemu-system-arm qemu-efi-aarch64`.
Нужны графическая сессия и доступ пользователя к `/dev/kvm`.
Запуск из распакованного каталога:

```sh
sh packaging/start-linux.sh
```

При первом запуске создаётся `environment.json`, загружается подписанный образ
Ubuntu подходящей архитектуры и готовится диск. Гость установит приложения сам.
Для нестандартного пути данных используйте явные команды:

```sh
python3 scripts/configure.py --data /absolute/path/to/private-vm
python3 scripts/prepare.py
python3 environment.py start
```

Если диск уже существует, подготовка откажется его перезаписывать.
На Linux/Windows пока нет подписки на сетевые события, аналогичной Darwin
`AF_ROUTE`: используется периодическая проверка внешнего IP. Проверка каждые
2 секунды и срок разрешения 6 секунд **не означают мгновенную защиту от утечки**.
Не используйте экспериментальные порты там, где критична мгновенная блокировка.

## Windows preview

Нужен Python 3.12+. `packaging/check-windows.cmd` запускает тесты общего ядра.
Это не установщик Windows-приложения и не готовая безопасная VM-среда.
Проверяются разбор запросов, блокировки шлюза, правила изоляции и формирование
команд; интеграция с QEMU и создание ISO требуют дальнейшей реализации/проверки.

## Сеть и границы изоляции

- QEMU: `restrict=on`, IPv6 отключён; единственный гостевой выход — шлюз
  `10.0.2.100:7890`. Гостевой nftables разрешает только шлюз, loopback и DHCP.
- `network_mode: system`, `web_access: public` позволяют публичный HTTPS:443
  и HTTP GET/HEAD:80. Локальные, служебные и непубличные IP блокируются.
  DNS разрешается один раз, проверяется и используется точный проверенный IP.
- `web_access: services` включает ограниченный список сервисов.
  Необязательный `network_mode: proxy` поддерживает локальный HTTP CONNECT proxy
  без авторизации, но только ограниченный список сервисов.
- Проверка IP идёт через тот же транспорт к Cloudflare trace (поля `ip`, `loc`);
  `colo` не используется как страна. Неизвестная страна, RU и ошибка проверки
  закрывают сеть. При смене IP блокировка остаётся до нового запуска среды.
- На Mac изменения маршрутов приостанавливают шлюз до свежей проверки.
  Проверка активных соединений каждые 20 мс — интервал контроля, а не обещание
  полного отсутствия пакетов после изменения маршрута.
- VPN с раздельной маршрутизацией может направлять разные сайты разными путями.
  Совпадение IP проверочного сервиса не доказывает маршрут каждого назначения.
- Временная ошибка проверки закрывает сеть, но после подтверждения прежнего IP
  она восстанавливается. HTTP 429 учитывает `Retry-After`.
- Гостевой пользователь без sudo; SSH, shared folders и clipboard отсутствуют.
  Chromium sandbox остаётся включён.
- Гость видит свою ОС, виртуальные устройства, свой IP и сведения аккаунта.
  Он не скрывает условия использования или географические правила сервиса.
- `--password-store=basic` убирает запрос keyring; дополнительных гарантий
  шифрования секретов в госте нет. Защищайте диск VM средствами хостовой ОС.

## CI/CD и безопасность

Каждый PR, push в main и тег запускает тесты на пяти runner-платформах.
Раз в неделю запускается повторная проверка зависимостей и кода.

- **SAST:** Bandit для Python; CodeQL для Python, Swift и GitHub Actions.
  Bandit medium/high и CodeQL security severity ≥4 блокируют релиз.
- **SCA:** pip-audit для закреплённых инструментов сборки/проверки; Trivy для
  исходников и реального дерева подписанных Debian-пакетов гостя на AMD64/ARM64.
  HIGH/CRITICAL, включая ещё не исправленные CVE, блокируют релиз.
- **Секреты:** Trivy сканирует текущие исходники. Диски VM, журналы и конфигурации
  пользователя исключены. Это не полная проверка истории Git.
- **SBOM:** CycloneDX и список точных версий гостевых пакетов сохраняются в Artifacts.
- Actions закреплены по SHA, Python-инструменты — версиями и хешами.
  Dependabot предлагает обновления еженедельно.
- По тегу, например `v0.2.0`, релиз публикуется только при успешных проверках.
  Все релизы пока помечаются prerelease; ZIP сопровождаются SHA256.

```sh
python3 -m unittest discover -s tests -v
python3 -m venv .venv
.venv/bin/pip install --require-hashes -r requirements-security.txt
.venv/bin/bandit -r environment.py network_guard.py network_transport.py route_guard.py macos scripts -ll
.venv/bin/pip-audit --strict --disable-pip --no-deps -r requirements-security.txt
```

Настройте branch protection с обязательным CI, если нужно запрещать слияние
непроверенных PR; файлы workflow сами по себе не меняют настройки репозитория.
Подробные ограничения покрытия и политика исправлений — [SECURITY.md](SECURITY.md).

Документация инструментов: [GitHub runners](https://docs.github.com/en/actions/reference/runners/github-hosted-runners),
[CodeQL](https://docs.github.com/en/code-security/reference/code-scanning/workflow-configuration-options),
[Trivy](https://trivy.dev/docs/latest/scanner/vulnerability/).
